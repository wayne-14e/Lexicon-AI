# 📚 Lexicon AI

> Stop collecting vocabulary in random notes. Build a vocabulary you actually remember.

## 💡 Why I built this

While preparing for the SAT, I realized something annoying.

Every vocabulary app I tried was either:
- expensive,
- full of ads,
- too simple,
- or forced me to manually write definitions, synonyms, and example sentences.

I also wanted an easy way to share my word lists with friends without sending screenshots.

So I built **Lexicon AI**.

It became much more than a vocabulary notebook—it's designed specifically for **SAT** and **IELTS** students who want one place to collect, study, practice, and share vocabulary.

---

# ✨ Features

### 🤖 AI-powered vocabulary
Paste a list of words and let Gemini generate:
- simple definitions
- parts of speech
- synonyms & antonyms
- memorable example sentences

No more writing everything yourself.

---

### 📄 Extract words from documents

Upload a PDF, DOCX or TXT file and automatically extract useful vocabulary.

Perfect for books, articles and class notes.

---

### 📚 Built-in SAT & IELTS archives

Study from curated vocabulary collections including:
- IELTS A1–C2
- SAT College Panda
- Erica Meltzer vocabulary

Unlock them with Scholar Tokens.

---

### 🎮 Learn instead of memorizing

Study using:
- Flashcards
- Matching Game
- AI-generated reading passages
- Pronunciation (AI TTS)

---

### 🔍 Search everything

Instantly search across all of your collections and unlocked archives.

---

### 🔗 Share collections

Every vocabulary journal can be shared with a public link.

No screenshots required.

---

### 🪙 Gamified learning

Earn Scholar Tokens by:
- maintaining streaks
- completing study sessions

Use them to unlock new vocabulary archives and AI features.

# 🚀 Running locally

```bash
git clone <repo>

npm install

npm run dev
```

Create a `.env.local` file:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
VITE_CLERK_PUBLISHABLE_KEY=
GEMINI_API_KEY=
```
